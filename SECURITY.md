# Security Policy

## Supported versions

Security fixes are released for the latest release of each maintained
major version (currently 2.x and 1.x).

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public issues or
pull requests.

Report them privately through GitHub: open the **Security** tab of this
repository and click **Report a vulnerability**.

Please include:

- the affected versions;
- a description of the problem and its impact;
- a minimal test or script that reproduces it;
- a suggested fix, if you have one.

The maintainer will acknowledge the report, work on a fix with you and
agree on the time of public disclosure.
